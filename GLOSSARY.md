# Thai Waldorf Teacher Skills

Planning and teaching support for science in a Thai Waldorf upper school (G9–G12 / ม.3–ม.6), framed by the storyline instructional model and epistemic agency. Terms shared with the author's thesis keep the thesis's meaning.

## Teaching structure

**Teaching sequence**:
An ordered run of units that pursues one set of learning intentions with one class. Main lesson blocks and subject lessons are both teaching sequences, differing in rhythm. A main lesson block is named by its own subject (meteorology, not science).
_Avoid_: Unit, course (except as a folder name)

**Unit**:
The primary building block of a teaching sequence: the sessions devoted to one topic. In an anticipated route each unit is either fixed (anchor, calendar-bound, putting pieces together) or interchangeable.
_Avoid_: Lesson set, module, chapter

**Main lesson block**:
A teaching sequence of daily sessions on one theme over 2–4 weeks, usually 100 minutes each, following the Waldorf learning rhythm across nights of sleep.
_Avoid_: Block, main lesson (alone), epoch, MLB

**Subject lesson**:
A teaching sequence that recurs in the weekly timetable across a term, often as one long and one short session per week. A Science Practice lesson is one kind.
_Avoid_: Track class, period, regular class

**Two-day rhythm**:
The default main-lesson rhythm for the upper school (after Zech): an experience is taken in on one day and left un-analysed; the next day its recall flows straight into discussion and concept formation, and later days apply the concept.
_Avoid_: Four-day cycle, E→R→C→A cycle (Rawson's general model, not the default here)

**Session**:
One timetabled meeting of a class within a teaching sequence, with its own duration.
_Avoid_: Lesson (when a single meeting is meant), period

## Context

**Class profile**:
A teacher-supplied description of one class (grade, grade mode, schedule pattern, learner variability, language), kept with each teaching sequence that class takes, that skills read before planning. When absent, the teacher states the context in the request.
_Avoid_: Class settings, roster

**Plugin layout**:
The section of a course folder's README that maps plugin concepts (class profile, unit plans, Thai core plans…) to the teacher's own files and folders. Proposed by detection, recorded only after the teacher confirms, then read by every skill instead of guessing again.
_Avoid_: Folder structure, config, settings

**Year plan**:
A teacher-supplied list of a school year's teaching sequences per grade and term, with the Thai indicators each one claims. The basis for coverage checks.
_Avoid_: Scope and sequence, curriculum map, timetable

**Grade mode**:
The developmental orientation of a Waldorf upper-school grade: G9 What, G10 How, G11 Why, G12 Who.
_Avoid_: Grade theme, stage

**Learner variability**:
The expected range of needs, strengths and languages in any class, designed for up front through UDL options, with targeted supports for anonymised needs.
_Avoid_: Mixed ability, ability levels, low/high learners

## Design

**Storyline instructional model**:
The NGSS-aligned model in which students' questions about an anchoring phenomenon drive cycles of sensemaking toward explanatory models (Reiser et al., 2021).
_Avoid_: Storyline (unqualified at first mention), Storyline Approach, Scottish Storyline, inquiry unit

**Storyline-based main lesson block**:
A main lesson block built on the storyline instructional model, with its routines fitted to the block's daily rhythm. The default design for main lesson blocks.
_Avoid_: Storyline unit, phenomenon-based block

**Anchoring phenomenon**:
The observable event, selected by the teacher, that opens a storyline-based main lesson block and from which students' questions are elicited.
_Avoid_: Hook, theme, topic

**Driving question**:
The question that frames a whole storyline-based main lesson block; with the anchoring phenomenon it is the highest-level curricular component, so a student decision about it reaches every later session. Its authorship is stated, not assumed.
_Avoid_: Deep question, block deep question; conflating it with the driving question board

**Driving question board**:
The public record of students' questions about the anchoring phenomenon, clustered by the class and treated as the collective mission of the block; an epistemic tool.
_Avoid_: Question board, question wall, parking lot

**Fixed sequence**:
A storyline-based main lesson block whose units run in an order set by the teacher in advance. The default.
_Avoid_: Linear plan, spine (unqualified)

**Anticipated route**:
A storyline-based main lesson block planned as a set of interchangeable units in an expected order, arranged during the block as the driving question board directs; only a few anchor points are fixed.
_Avoid_: Emergent plan, flexible sequence, lesson-set bank

**Target idea**:
An idea the class must figure out during the teaching sequence; never taught beforehand.
_Avoid_: Learning objective, key concept, answer

**Prerequisite idea**:
An idea the teaching sequence assumes students already hold, taught beforehand.
_Avoid_: Background knowledge, prior knowledge (students' own ideas)

**5E inquiry**:
The IPST-recommended inquiry cycle (Engage, Explore, Explain, Elaborate, Evaluate). The default design for subject lessons; how its phases fall across sessions and plan stages follows the design, not a fixed mapping.
_Avoid_: Inquiry cycle (unqualified), 7E

## Epistemic agency

**Epistemic decision**:
A classroom decision that drives knowledge-building and whose authorship can rest with teacher or students, in three domains: investigation aim, investigation method, explanatory model (Ko & Krist, 2019).
_Avoid_: Choice, student voice

**Opening**:
A teacher's act of handing an epistemic decision to students, described by the domain opened and its reach into later sessions.
_Avoid_: Giving agency, empowering

**Epistemic agency audit**:
A diagnostic reading of a planned teaching sequence that reports, session by session, which epistemic decisions are opened or closed and why. It reads the design only, never enacted uptake, and never rewrites the plan.
_Avoid_: Agency check, student-voice review

## Assessment

**Assessment for learning**:
Evidence the teacher gathers during a teaching sequence to decide the next instructional step.
_Avoid_: Formative assessment (when the purpose matters), quick check

**Assessment as learning**:
Students monitoring and judging their own learning against criteria they understand; never scored. Not counted as uptake, since it concerns individual learning rather than the class's knowledge work.
_Avoid_: Self-assessment (only one form of it), reflection (unqualified), metacognition (the process, not the assessment purpose)

## Curriculum alignment

**Curriculum crosswalk**:
A matrix relating Thai indicators, Waldorf grade and block placement, and PISA-adapted competencies, keeping each framework's own wording and showing gaps rather than merging them.
_Avoid_: Alignment map, merged framework

**Sequencing difference**:
A case where a teaching sequence addresses a Thai indicator assigned to a different ม. grade than the one taught; the indicator is cited as written and justified by grade mode.
_Avoid_: Misalignment, off-grade indicator

## Plan documents

**Thai core plan**:
The แผนการจัดการเรียนรู้ in Core Curriculum B.E. 2551 layout, with K-P-A objectives and the stages ขั้นนำ / ขั้นสอน / ขั้นสรุป, written for external supervision.
_Avoid_: Lesson plan (unqualified), OBEC plan

**Waldorf plan**:
The school's internal main-lesson planning documents at three scales: block plan (แผนรายบล็อก), week plan (แผนรายสัปดาห์), and day plan (แผนรายวัน).
_Avoid_: Steiner plan, ML plan

## Delivery documents

**Delivery document**:
A document for teaching one session rather than planning it: the preparation note, the run sheet and the supporting-teacher brief. Written in Thai, printed, and read by other adults as well as the teacher.
_Avoid_: Prep notes (for all three), handouts

**Preparation note** (บันทึกเตรียมสอน):
A one-page run-through of one planned session, read the evening before: anticipated student responses with dialogic moves, timings, equipment and setup, and risk notes. Never changes the plan.
_Avoid_: Prep note, prep sheet, lesson notes

**Run sheet** (ใบลำดับการสอน):
A one-page running order of one session, kept at hand while teaching: clock times, parts, cue lines and materials per part, with no reasoning. Built from the session plan and its preparation note.
_Avoid_: Timeline, agenda, lesson outline

**Supporting teacher** (ครูประกบ):
An adult in the room for some or all of a session who supports the students with learning differences, not the class or the equipment.
_Avoid_: Teaching assistant, TA, co-teacher, shadow teacher

**Supporting-teacher brief** (บันทึกสำหรับครูประกบ):
A note for the supporting teacher about one whole session: what happens when, which supports to give at each part, what to watch for, and when to step in or step back. It also marks the parts after the supporting teacher leaves, flagging the demanding ones so follow-up with the students can be planned. Students are named only by anonymised code, or by need when the class has no codes.
_Avoid_: Handover, TA notes

**Exported copy**:
A printable copy of a plan or delivery document, made from it in the delivery format the teacher chose for the course. Never edited itself: when the document changes, the copy is made again.
_Avoid_: Printout (for the file), export (as a noun), version

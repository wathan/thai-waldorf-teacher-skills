# Output language follows the audience

A file the plugin writes defaults to Thai when it will be shared with someone other than the teacher and the agents, and to English when only the teacher and the agents read it. Shared: Waldorf plans (block, week, day; read by colleagues and the school), Thai core plans (external supervision), the course standards map and year coverage report (shown to supervisors). Teacher-and-agent only: class profile, course README "Plugin layout", differentiation plan, agency audit, formative assessment plan, preparation notes. The teacher can ask for the other language for any file. Thai official terms (indicator codes and wording, skill and attitude names, ปีการศึกษา) are quoted verbatim in either language, and student-facing material follows the class profile's language of student materials.

This narrows spec #1's "plans in English by default": the teacher writes and supervisors read the shared documents in Thai, while working files stay in the language the teacher and agents plan in.

## Consequences

- Each skill states which side of the rule its outputs fall on; a new skill decides by asking who besides the teacher will read the file.
- Replies to the teacher stay in plain teacher language whatever the file language.

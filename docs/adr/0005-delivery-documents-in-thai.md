# Delivery documents are written in Thai

Preparation notes, run sheets and supporting-teacher briefs default to Thai. They are used in the classroom, are printed, and are read by other adults such as the supporting teacher (ครูประกบ), so they count as shared documents. This narrows ADR-0004, which listed preparation notes as teacher-and-agent only and so English. Design working files (class profile, differentiation plan, agency audit, formative assessment plan) stay in English.

## Consequences

- `preparing-to-teach` writes its preparation note and run sheet in Thai, and the differentiation skill writes the supporting-teacher brief in Thai, quoting from English design files as needed.
- The teacher can still ask for English in any file.

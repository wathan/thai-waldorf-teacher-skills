# Thai core plans for subject lessons: one per 5E cycle

One Thai core plan per 5E cycle of a subject lesson unit, never one per session. Subject lessons have no Waldorf plans: each plan is written from the unit plan and the cycle plan that `planning-subject-lessons` writes. This file says what each plan is written from, how the cycle's phases land on ขั้นนำ / ขั้นสอน / ขั้นสรุป, and what to check. The section-by-section form rules are in `filling-the-form.md`.

## Sources

Read these at the layout's mapped locations before writing:

1. **Unit plan** (`unit plans`): the cycles in order, the Thai indicators the unit claims and any sequencing differences, grade mode, target ideas. Without a unit plan for the unit asked for, write nothing: say the unit needs designing first with `planning-subject-lessons`.
2. **Cycle plan** for each cycle in scope (`session plans`): the main source. Its stage mapping, sessions, phases in order, minutes, prompts, UDL options, equipment and assessment go into the Thai core plan. A cycle the unit plan lists but with no cycle plan gets no Thai core plan: say so and offer it through `planning-subject-lessons`.
3. **Standards map**, if mapped: the unit's claimed indicators when the unit plan lists only codes.

**Scope.** "The Thai core plans for unit 2" means one per cycle of unit 2. A request for a single session's plan is answered with its cycle's plan; say so in one line.

## Naming and numbering

- **Plan number:** แผนการจัดการเรียนรู้ที่ = the cycle's position in the subject lesson counted across units (unit 1 cycles 1–2 are plans 1–2; unit 2 cycle 1 is plan 3), unless the course's existing Thai core plans already number differently, in which case continue theirs.
- **Unit:** หน่วยการเรียนรู้ที่ and its เรื่อง = the unit plan's number and Thai title. **Plan title:** the cycle's title in Thai.
- **Time:** the sum of the cycle's session lengths from the class profile, written exactly (100 + 50 + 100 minutes: `4 ชั่วโมง 10 นาที`), never rounded; add the number of sessions (e.g. `(3 คาบ)`).
- **Files** in a folder location: `unit-01-cycle-01-thai-core-plan.md`, … (two-digit unit and cycle numbers).

## Stage mapping follows the design

The design decides where each phase falls; there is no fixed 5E-to-stage mapping (glossary: 5E inquiry).

1. **The cycle plan states its mapping** (its "Thai core plan stages" section): follow it exactly. Each stage lists what the cycle does there, in the cycle plan's order, with minutes.
2. **No stated mapping:** derive it from where the phases actually fall: ขั้นนำ holds what opens the cycle (Engage, with any opening retrieval practice); ขั้นสอน holds the main work in order (Explore, Explain, Elaborate, and Evaluate parts that steer teaching); ขั้นสรุป holds what closes the cycle (the students' or class's summary, a closing Evaluate, the exit slip). Say in the reply that the mapping was derived and offer to record it in the cycle plan.
3. **Label every step with its phase** in IPST's Thai names (ขั้นสร้างความสนใจ, ขั้นสำรวจและค้นหา, ขั้นอธิบายและลงข้อสรุป, ขั้นขยายความรู้, ขั้นประเมิน) and its session (คาบที่ 1, คาบที่ 2 …), numbered within each stage with minutes and the UDL option in brackets. Retrieval practice keeps its own label (การฝึกดึงความรู้จากความจำ / ทบทวนความรู้เดิม). A phase that spans sessions appears once per session where it happens.
4. **Never move** a phase to another stage to look conventional, never add a phase the cycle does not have, and never fill a stage with something from another cycle.
5. **Explicit instruction and graded practice** go where the cycle plan puts them (inside Explain or Elaborate), described as they run (teacher models, class does together, students practise).
6. **ชิ้นงาน/ภาระงาน:** the products the cycle makes (data tables, graphs, written explanations, practice sheets, the Evaluate task).
7. **Measurement:** the cycle's scored Evaluate work gets rubrics as `filling-the-form.md` describes; retrieval practice and hinge questions are named as assessment for learning without a score; exit slips and self-assessment as assessment as learning (การประเมินเพื่อการเรียนรู้ของตนเอง, ไม่ให้คะแนน).
8. **Hour-by-hour detail:** one section per session (คาบที่ n, its day and length), with its timed rows from the cycle plan.

## Consistency check

Compare every Thai core plan with the unit plan and its cycle plan. Report each finding in the reply (which cycle, which session, what differs) and say which way the Thai core plan went. Never change the unit plan or a cycle plan unasked; offer to fix it through `planning-subject-lessons`.

| Check | If it fails |
|---|---|
| The Thai core plan has the cycle plan's phases, steps and order, under the stages its mapping states | Fix the Thai core plan to follow the cycle plan |
| Each session's minutes add up to its length in the class profile | Report the total against the session length; write the plan's time as the sessions' real lengths and keep the cycle plan's split, noting the excess for the teacher |
| The cycle plan's sessions match the class profile's weekly pattern (days and lengths) | Report the difference; the Thai core plan follows the class profile's session lengths |
| The phases run Engage, Explore, Explain, Elaborate, Evaluate in order; Explain does not come before Explore | Report it; describe the cycle as planned, without reordering |
| The indicators are among those the unit plan (or standards map) claims | Use only claimed indicators; if the cycle needs another, report it and offer to add it to the unit plan |
| Retrieval practice, hinge questions, exit slips or self-assessment are scored in the cycle plan | Report it; the Thai core plan names them without a score |

# Storyline design for a subject lesson unit

Only when the teacher asks for it. The rules for the anchoring phenomenon, the driving question and its authorship, target and prerequisite ideas and the driving question board are those of `storyline-design.md` (planning-main-lesson-blocks), read with "unit" in place of "block". This file says how they fit a subject lesson: weekly sessions instead of daily ones, and 5E cycles inside the unit.

## The unit's shape

- **The unit stays one topic, made of 5E cycles.** The storyline frames the cycles; each cycle still runs Engage, Explore, Explain, Elaborate, Evaluate and still gets one Thai core plan.
- **Anchoring phenomenon:** the teacher's choice. If none is chosen, offer three or four candidates as `storyline-design.md` describes and ask; never choose, never rank, and write no plan files until the teacher names one. The unit plan says the teacher chose it.
- **Driving question:** drafted for the unit, with its authorship stated in one line (e.g. teacher-drafted, provisional; the class revisits it at the driving question board).
- **Target ideas and prerequisite ideas:** listed separately, each target idea tied to the cycle where the class is expected to reach it.
- **Cycles in a fixed order** by default, each marked fixed; the board frames how each cycle's question is taken up, not the order.

## The cycles inside the storyline

| Phase | In a storyline unit |
|---|---|
| Engage (cycle 1) | The anchoring phenomenon, experienced as fully as the session allows; students write what they notice and wonder |
| Engage (later cycles) | Back to the driving question board: which of our questions does this cycle take up, and what do we already think? |
| Explore | Investigations that answer the board's questions |
| Explain | Students' own explanations compared and built into the class's shared model of the phenomenon, revised each cycle; the teacher's terms and formulae come after |
| Elaborate | Using the model on a new case or back on the anchor |
| Evaluate | Includes returning to the board: answered questions marked, new ones added |

The last cycle brings the pieces together at the anchoring phenomenon and the driving question.

## The driving question board across the weeks

- **Built from students' own questions** in cycle 1, in the session after the anchor where the anchor fills a session (individual questions first, then clustered by the class), or straight after the anchor when time allows. Never write students' questions into the plan: name only the kind of questions you expect, so cycles can be linked to them.
- **Revisited at each cycle's Engage** and whenever an investigation raises new questions.
- **Weekly gaps:** after the anchor or an investigation, the next session opens by recalling what the class saw, from memory, before discussing it.
- If the layout maps a `driving question board` location, say in the unit plan that the board's record lives there; do not write the record (it comes from the class).

## In the unit plan

Add above the cycle table, in this order: the anchoring phenomenon (chosen by the teacher), the driving question with its authorship, then the target and prerequisite ideas, and a line on how the board is used. Mark each cycle fixed.

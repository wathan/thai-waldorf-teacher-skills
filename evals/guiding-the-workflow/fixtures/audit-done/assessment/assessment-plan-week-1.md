# Assessment plan: week 1

## Assessment for learning

- Day 3 hinge question: "Where does the dye go first, and why?" (four options from common misconceptions).
- Main lesson book storm models, checked Tue and Fri for how the explanation changes.

## Assessment as learning

- Day 5 exit slip: "How well can I now explain the storm? What is still unclear?" (not scored).
- Single-point rubric for "a good model of the storm", criteria agreed by the class on day 4.
